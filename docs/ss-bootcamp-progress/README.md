# SS BootCamp Progress

This directory keeps public-safe progress notes for Manalio during Singularity Society BootCamp.

Manalio supports students in turning practicum experiences into records and reflection, while helping teachers use post-practicum learning processes for individual support and class instruction. These notes show visible product progress, current learning, and the next validation target without exposing private review links, credentials, school names, educator names, student data, or practicum-site information.

## How To Read

- `weekly-updates/` contains short weekly progress notes.
- Latest: `weekly-updates/2026-W28.md`
- Current weekly submission: `SingularitySociety/bootcamp004` PR #400 is awaiting approval. Slack posting is deferred until the PR is merged.
- Each note focuses on product progress, safety decisions, validation learning, and the next concrete step.
- Internal runbooks, limited-review access details, private environment values, and real-world case details are intentionally excluded.

## Public Sharing Rules

- Do not include real student, child, school, educator, family, or practicum-site information.
- Do not include login details, private preview links, environment values, API keys, cookies, or database information.
- Keep claims at the current evidence level: interactive public demo, local safety validation, educator review in progress, and small-scope PoC preparation.
