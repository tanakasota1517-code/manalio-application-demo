# SS BootCamp Progress

This directory keeps public-safe progress notes for Manalio during Singularity Society BootCamp.

Manalio is still a PoC-stage prototype. These notes are meant to show steady progress, current learning, and the next validation target without exposing private review links, credentials, school names, educator names, student data, or practicum-site information.

## How To Read

- `weekly-updates/` contains short weekly progress notes.
- Each note should focus on visible product progress, safety decisions, validation results, and the next concrete step.
- Internal runbooks, limited-review access details, private environment values, and real-world case details are intentionally excluded.

## Public Sharing Rules

- Do not include real student, child, school, educator, family, or practicum-site information.
- Do not include login details, private preview links, environment values, API keys, cookies, or database information.
- Do not present Manalio as a production deployment, a diary-writing shortcut, or an auto-grading system.
- Keep claims at the current evidence level: PoC-stage prototype, educator review in progress, and small-scope validation.
