# 2026-W28 Progress

## Current Stage

Manalio is narrowing its practical core for an internal school review by October 2026 and a small-scope PoC around January 2027. Educator feedback is still pending, so development continues on the student workflow, post-practicum teacher support, and failure-safe API boundaries that can be verified locally.

## What Changed This Week

- The student screen now starts with a short chat about the day's practicum goal and one observed episode instead of opening with a long form.
- After the chat, students compare their original notes with an unfinished writing scaffold, then move into the school-format editor and revise the record in their own words.
- The teacher screen was narrowed to a 50-student list, individual support points, and recurring themes that may need to be addressed in class after practicum.
- Authenticated screens search school-approved display names, while the public demo searches anonymous codes. Internal selection IDs are never search targets.
- Authentication and school-format APIs now stop on malformed or ambiguous upstream responses instead of silently substituting data or clearing a valid session.
- The API boundary audit passes 172 checks. No production database migration or external AI request was used for this validation.

## Current Constraints

- The real school diary format has not yet been applied, so field order, episode count, and expected writing length still need validation.
- The next product decision should come from students and teachers using the flow, not from adding more controls to the first screen.
- The public repository and demo must be refreshed only from the sanitized public candidate, never from the full working repository.

## Next Focus

- Test the wording, answer length, and screen transitions with the student flow.
- Confirm that teachers can reach the right student and support material quickly in a 50-student list.
- Adapt the editor after receiving the school's actual diary format.
